# Flipbook Canvas — System Style Constraints (全息镭射)

All canvases share these constraints. This is a **抖音图文 (Douyin photo-text)** deck — every image must be a scroll-stopping vertical poster with holographic / iridescent aesthetics.

- **Format**: vertical 9:16 (1080×1920), mobile-first, single coherent holographic scene.
- **Visual style**: holographic / iridescent foil look — shifting rainbow gradients, liquid chrome and metallic reflections, prismatic light refraction, soft 3D blobs, glossy mirror surfaces, futuristic premium tech vibe. Think iridescent sticker / Y2K aero-chrome / luxury gadget render — slick, glossy, eye-catching.
- **Background**: smooth iridescent rainbow gradient (pearl pink → cyan → lilac → mint, #FFB6E6 #A0E9FF #C9B6FF #B6FFD9) with soft caustic light streaks. Never beige, never flat matte, never dark gritty.
- **Headline (爆款钩子)**: every image carries ONE huge bold Chinese headline (4–10 字) in glossy liquid-chrome 3D letters with rainbow reflection, top or bottom third — a hook/number, not a description. Examples: "未来感拉满", "高级质感", "限量联名".
- **Callouts**: 6–12 short punchy labels (1–6 字 each) inside glossy iridescent pills / chrome chips near key objects, with eye-catching numbers/units. Big enough to read on a phone.
- **Focal hierarchy**: one glossy chrome/iridescent hero subject dominates with strong specular highlights; callouts read as slick UI chips.
- **Consistency**: every page feels from the same premium render — same iridescent palette, same chrome treatment, same glossy lighting, same headline style.

Append the following suffix to **every** ImageGen prompt:
> `, holographic iridescent vertical 9:16 poster illustration, shifting rainbow gradient (pearl pink #FFB6E6 cyan #A0E9FF lilac #C9B6FF mint #B6FFD9), liquid chrome and metallic reflections, prismatic light refraction, glossy mirror surfaces, soft 3D blobs, Y2K aero-chrome premium tech vibe, glossy liquid-chrome 3D Chinese headline with rainbow reflection, iridescent callout chips, ONE huge bold Chinese headline plus punchy numeric callouts, mobile-first vertical composition`

Negative cues (if model supports):
> `flat isometric diagram, beige background, muted desaturated colors, matte flat shapes, tiny cramped text, horizontal 16:9, dense paragraphs, watermarks, dark gritty, hand-drawn, ink wash, grainy riso`
