# Flipbook Canvas — System Style Constraints (黏土3D)

All canvases share these constraints. This is a **抖音图文 (Douyin photo-text)** deck — every image must be a scroll-stopping vertical poster with soft 3D clay / claymorphism aesthetics.

- **Format**: vertical 9:16 (1080×1920), mobile-first, single coherent 3D clay scene.
- **Visual style**: cute soft 3D clay-render look (claymorphism) — rounded plasticine/play-doh shapes, matte clay texture with tiny surface dimples, soft inflated volumes, gentle global-illumination soft shadows, playful macaron / candy color blocking. Think Pixar-soft 3D icon set, toy-like and tactile — not flat, not photoreal.
- **Background**: solid soft pastel or gentle two-tone gradient (mint #B8F2E6, peach #FFD8BE, lavender #E2C2FF, sky #BDE0FE) with a soft drop shadow under the hero. Never beige #F5EFE6, never harsh, never dark.
- **Headline (爆款钩子)**: every image carries ONE huge bold Chinese headline (4–10 字) rendered as chunky rounded 3D clay letters (extruded, soft bevel, candy color), top or bottom third — a hook/number, not a description. Examples: "一捏就懂", "萌翻全场", "3秒上手".
- **Callouts**: 6–12 short punchy labels (1–6 字 each) inside rounded clay pills / soft bubbles, near key objects with short rounded leader dots, with eye-catching numbers/units. Big enough to read on a phone.
- **Focal hierarchy**: one chunky clay hero subject dominates, soft-shadowed and centered; callouts orbit it cleanly.
- **Consistency**: every page in the same flipbook feels sculpted by the same hand — same clay texture, same soft lighting, same macaron palette, same rounded headline treatment.

Append the following suffix to **every** ImageGen prompt:
> `, soft 3D claymorphism vertical 9:16 poster illustration, rounded matte plasticine clay texture with tiny surface dimples, inflated tactile toy-like volumes, soft global-illumination shadows, playful macaron candy color palette (mint #B8F2E6 peach #FFD8BE lavender #E2C2FF), chunky rounded 3D clay Chinese headline, callouts in soft rounded clay pills, cute cheerful clean composition, ONE huge bold Chinese headline plus punchy numeric callouts, mobile-first vertical composition`

Negative cues (if model supports):
> `flat isometric diagram, beige background, muted desaturated colors, tiny cramped text, horizontal 16:9, dense paragraphs, watermarks, realistic photo, dark gritty, sharp hard edges, line-art, neon cyberpunk`
