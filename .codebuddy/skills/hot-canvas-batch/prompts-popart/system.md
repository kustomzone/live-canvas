# Flipbook Canvas — System Style Constraints (波普漫画)

All canvases share these constraints. This is a **抖音图文 (Douyin photo-text)** deck — every image must be a scroll-stopping vertical poster with pop-art comic-book aesthetics.

- **Format**: vertical 9:16 (1080×1920), mobile-first, single coherent pop-art scene.
- **Visual style**: retro pop-art comic-book look — bold thick black ink outlines, Ben-Day halftone dot shading, primary high-saturation colors (red #ED1C24, yellow #FFDE17, blue #0072BC), comic action bursts and speech balloons, "BAM!"/"WOW!" explosion bubbles, dynamic motion lines. Think Lichtenstein / vintage comic panel — loud, punchy, energetic.
- **Background**: a flat primary color or halftone-dot field, sometimes with radial burst lines from the hero. Never beige, never muted, never photoreal.
- **Headline (爆款钩子)**: every image carries ONE huge bold Chinese headline (4–10 字) inside a jagged comic explosion bubble or bold outlined comic font, top or bottom third — a hook/number, not a description. Examples: "震惊全网", "炸裂现场", "笑不活了".
- **Callouts**: 6–12 short punchy labels (1–6 字 each) in small comic speech bubbles / starburst tags near key objects, with eye-catching numbers/units. Big enough to read on a phone.
- **Focal hierarchy**: one bold outlined hero subject dominates with burst lines emphasizing it; bubbles read as energetic callouts.
- **Consistency**: every page feels from the same comic — same primary palette, same halftone dots, same thick outlines, same explosive headline treatment.

Append the following suffix to **every** ImageGen prompt:
> `, retro pop-art comic-book vertical 9:16 poster illustration, bold thick black ink outlines, Ben-Day halftone dot shading, primary high-saturation colors (red #ED1C24 yellow #FFDE17 blue #0072BC), comic action bursts and speech balloons, BAM/WOW explosion bubbles, dynamic motion lines, Lichtenstein vintage comic vibe, comic-explosion-bubble Chinese headline, starburst callout tags, ONE huge bold Chinese headline plus punchy numeric callouts, mobile-first vertical composition`

Negative cues (if model supports):
> `flat isometric diagram, beige background, muted desaturated colors, photoreal, tiny cramped text, horizontal 16:9, dense paragraphs, watermarks, neon glow, dark cyberpunk, glossy chrome, smooth 3D render, ink wash`
