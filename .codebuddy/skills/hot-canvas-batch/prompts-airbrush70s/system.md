# Flipbook Canvas — System Style Constraints (复古喷绘)

All canvases share these constraints. This is a **抖音图文 (Douyin photo-text)** deck — every image must be a scroll-stopping vertical poster with 70s airbrush retro aesthetics.

- **Format**: vertical 9:16 (1080×1920), mobile-first, single coherent 70s airbrush scene.
- **Visual style**: 1970s airbrush retro look — smooth airbrushed gradients, warm earthy sunset palette, bold horizontal stripe sun, soft glow halos, grainy print texture, rounded retro display typography. Think vintage travel poster / 70s album cover / NASA worm-era — warm, nostalgic, mellow.
- **Background**: warm sunset gradient (burnt orange #E87A41, mustard #E8B04B, brown #8C5A3C, cream #F2E3C6) with a striped retro sun and soft haze. Never beige flat #F5EFE6, never neon, never cold.
- **Headline (爆款钩子)**: every image carries ONE huge bold Chinese headline (4–10 字) in a rounded retro display font, warm cream or orange, slight airbrush glow, top or bottom third — a hook/number, not a description. Examples: "回到七十年代", "复古风潮", "怀旧一刻".
- **Callouts**: 6–12 short punchy labels (1–6 字 each) in rounded retro badges / stripe tags near key objects, with eye-catching numbers/units. Big enough to read on a phone.
- **Focal hierarchy**: one warmly-lit hero subject dominates against the striped sun; callouts read as retro badges.
- **Consistency**: every page feels from the same 70s set — same warm palette, same striped sun, same grain, same rounded headline treatment.

Append the following suffix to **every** ImageGen prompt:
> `, 1970s airbrush retro vertical 9:16 poster illustration, smooth airbrushed gradients, warm earthy sunset palette (burnt orange #E87A41 mustard #E8B04B brown #8C5A3C cream #F2E3C6), bold horizontal-stripe retro sun, soft glow halos, grainy print texture, rounded 70s retro display typography, vintage travel-poster / 70s album-cover vibe, rounded retro Chinese headline with warm airbrush glow, retro badge callout tags, ONE huge bold Chinese headline plus punchy numeric callouts, mobile-first vertical composition`

Negative cues (if model supports):
> `flat isometric diagram, beige paper background, cold colors, neon glow, dark cyberpunk, glossy chrome, tiny cramped text, horizontal 16:9, dense paragraphs, watermarks, pixel art, sharp hard line-art, photoreal`
