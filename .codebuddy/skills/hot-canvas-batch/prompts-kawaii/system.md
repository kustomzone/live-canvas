# Flipbook Canvas — System Style Constraints (治愈卡通)

All canvases share these constraints. This is a **抖音图文 (Douyin photo-text)** deck — every image must be a scroll-stopping vertical poster with cute kawaii flat-cartoon aesthetics.

- **Format**: vertical 9:16 (1080×1920), mobile-first, single coherent kawaii cartoon scene.
- **Visual style**: cute kawaii flat-cartoon look — rounded chubby shapes, simple thick-or-no outlines, big sparkly eyes, blush cheeks, smiling faces on objects, candy/pastel palette, sticker-like icons, little sparkles ✨ and hearts. Think LINE Friends / Sanrio / cute infographic — friendly, soft, instantly likeable.
- **Background**: solid candy pastel or gentle gradient (sky blue #AEE6FF, lemon #FFF3B0, mint #C8F7C5, pink #FFCFE1) with a few floating cute doodads (clouds, stars, sparkles). Never beige flat, never dark, never photoreal.
- **Headline (爆款钩子)**: every image carries ONE huge bold Chinese headline (4–10 字) in a chunky rounded bubbly font with a contrasting outline, top or bottom third — a hook/number, not a description. Examples: "超简单", "一看就会", "萌系科普".
- **Callouts**: 6–12 short punchy labels (1–6 字 each) inside rounded sticker bubbles / cloud tags near key objects, with eye-catching numbers/units. Big enough to read on a phone.
- **Focal hierarchy**: one adorable mascot/hero subject dominates, centered and smiling; sticker callouts orbit it cleanly.
- **Consistency**: every page feels from the same cute brand — same pastel palette, same rounded shapes, same sparkle treatment, same bubbly headline.

Append the following suffix to **every** ImageGen prompt:
> `, cute kawaii flat-cartoon vertical 9:16 poster illustration, rounded chubby shapes, simple thick clean outlines, big sparkly eyes and blush cheeks, smiling faces on objects, candy pastel palette (sky blue #AEE6FF lemon #FFF3B0 mint #C8F7C5 pink #FFCFE1), sticker-like icons, floating sparkles and hearts, LINE-Friends/Sanrio friendly vibe, chunky rounded bubbly Chinese headline with outline, rounded sticker callout bubbles, ONE huge bold Chinese headline plus punchy numeric callouts, mobile-first vertical composition`

Negative cues (if model supports):
> `flat isometric diagram, beige background, muted desaturated colors, photoreal, dark gritty, tiny cramped text, horizontal 16:9, dense paragraphs, watermarks, neon cyberpunk, glossy chrome, ink wash, scary, realistic`
