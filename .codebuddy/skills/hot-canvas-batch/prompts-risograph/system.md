# Flipbook Canvas — System Style Constraints (套印孔版)

All canvases share these constraints. This is a **抖音图文 (Douyin photo-text)** deck — every image must be a scroll-stopping vertical poster with risograph / screen-print aesthetics.

- **Format**: vertical 9:16 (1080×1920), mobile-first, single coherent riso-print scene.
- **Visual style**: risograph / screen-print look — 2–3 spot inks overprinted with deliberate slight misregistration (offset color edges), heavy grain and noise, visible halftone/stipple texture, flat bold shapes, limited palette of vivid riso inks (fluorescent pink #FF48B0, bright blue #0078BF, yellow #FFD200, teal #00A98F). Think indie zine / gig poster — tactile, imperfect, punchy.
- **Background**: one flat riso ink fill or simple two-ink overlap with grain; off-white paper showing through. Never smooth gradient, never photoreal.
- **Headline (爆款钩子)**: every image carries ONE huge bold Chinese headline (4–10 字) in a heavy condensed sans, one spot ink, slightly misregistered for that printed look, top or bottom third — a hook/number, not a description. Examples: "限量首发", "手作温度", "复古印刷".
- **Callouts**: 6–12 short punchy labels (1–6 字 each) in a second spot ink, near key objects with simple leader lines or stamped tags, with eye-catching numbers/units. Big enough to read on a phone.
- **Focal hierarchy**: one bold flat hero shape dominates; overprint texture and grain unify the page.
- **Consistency**: every page feels printed on the same riso machine — same 2–3 inks, same grain, same misregistration, same headline treatment.

Append the following suffix to **every** ImageGen prompt:
> `, risograph screen-print vertical 9:16 poster illustration, 2-3 spot inks overprinted with slight misregistration offset edges, heavy grain and noise, visible halftone stipple texture, flat bold shapes, vivid riso palette (fluorescent pink #FF48B0, bright blue #0078BF, yellow #FFD200), off-white paper showing through, heavy condensed Chinese headline in one spot ink, second-ink callout tags, indie zine aesthetic, ONE huge bold Chinese headline plus punchy numeric callouts, mobile-first vertical composition`

Negative cues (if model supports):
> `smooth gradients, photoreal, 3D render, beige isometric diagram, tiny cramped text, horizontal 16:9, dense paragraphs, watermarks, neon glow, dark cyberpunk, glossy chrome`
